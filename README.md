# FreshTrack – Grocery Manager

 -FreshTrack is a Grocery Management Application. 
 -This helps the users to organize their Groceries, Monitor the expiry dates of their products. Which helps them in reducing the food wastage in their household.

## Features
- User registration and login using Supabase Authentication.
- Secure user-specific grocery management.
- Add, edit, and delete grocery items.
- Search groceries by name.
- Filter groceries by category.
- Track grocery expiry dates.
- Identify expired and soon-to-expire items.
- Dashboard statistics.
- Responsive interface for desktop and mobile screens.

## Technologies Used

- Flutter
- Dart
- Supabase
- PostgreSQL
- Visual Studio Code
